# DNA Orbit 意思決定ログ

## Decision ID

`ADR-004`

## 日付

2026-07-30

## 状態

- Accepted (supersedes ADR-003's `sourceA = M + p*S` / `sourceB = M - p*S` design)

## 題名

Phase 2.5: Stereo Preserveの物理的前提を再検証し、「Mid軌道 + 独立したSide bed」方式へ移行する

## 背景

ADR-003で採用した設計は、こう説明していた:「対称性100%では`xB = -xA`が
常に成り立つので、幾何学的中心は常に0である。ゆえにStereo Preserveを
上げても中心が0であるという体験は損なわれない」。

この説明は**位置**についてのみ正しく、**エネルギー**については何も
保証していなかった。`sourceA = M + p*S`、`sourceB = M - p*S`という式は、
入力がL/Rで非対称(例: L-onlyやハードパンされた素材)なとき、Strand Aと
Strand Bの**音量**を大きく偏らせる。位置は正確に対蹠のままでも、片方の
ストランドがもう片方よりはるかに大きい音を持っていれば、聴感上の重心は
音量の大きいストランドの位置へ引き寄られる。これは「DNAの中心が常に0で
ある」という製品コンセプトの核を、位置のレベルでは保ちながらエネルギーの
レベルで裏切る、という設計上の欠陥だった。

## 1. 4つの概念の定義

再検証にあたり、これまで曖昧に扱っていた「中心」を4つの独立した概念として
定義する。

| 概念 | 定義 | 何を保証するか |
|---|---|---|
| **幾何学的中心** | `(xA + xB) / 2`。Symmetry 100%では`xB = -xA`なので常に0 | 2つのストランドの**位置**の中点が0であること。音量には無関係 |
| **エネルギー加重中心** | `(xA*E_A + xB*E_B) / (E_A + E_B)`。`E_A`,`E_B`はStrand A/Bの**ソース信号**の(長期)パワー | 「音量を考慮した」実質的な重心。`E_A ≠ E_B`なら幾何学的中心が0でもここは0からずれる |
| **出力L/Rバランス** | `RMS(outL)` vs `RMS(outR)`(またはそのdB差) | 出力そのものの左右レベル差。ストランドの話ではなく、Wet信号全体(Core・Stereo Preserve bed含む)の特性 |
| **聴感上の中心** | 実際の人間の知覚(ILD/ITD、周波数依存の定位知覚を含む) | 本プロジェクトでは直接測定できない。出力L/Rバランスや相関を**プロキシ**として使うが、これは近似であり真の心理音響モデルではないと明記する |

エネルギー加重中心の**バイアス**は次式で近似できる(対称ロック時、
`xB = -xA`を代入):

```
bias = xA * (E_A - E_B) / (E_A + E_B)
```

`E_A = E_B`なら`bias = 0`(幾何学的中心と一致)。`E_A ≠ E_B`なら、
幾何学的中心が0でもバイアスは非0になる。

## 2. ADR-003方式(`sourceA = M + p*S`)の解析的な問題

L-only入力(`L = x`, `R = 0`)を例に、定常信号として厳密に計算する
(シミュレーションではなく閉形式の導出。定常信号に対しては近似ではなく
厳密な答えが出るため、むしろノイズを含む数値実験より信頼できる)。

```
M = x/2, S = x/2
sourceA(p) = M + p*S = (x/2)(1+p)
sourceB(p) = M - p*S = (x/2)(1-p)

E_A(p) / E_B(p) = ((1+p)/(1-p))^2
bias_fraction(p) = (E_A - E_B)/(E_A + E_B) = 2p / (1 + p^2)
```

| p | bias_fraction |
|---:|---:|
| 0% | 0.000 (問題なし - 旧挙動と同一) |
| 25% | 0.471 |
| 50% | 0.800 |
| **70%(既定値)** | **0.940** |
| 100% | 1.000(Strand Bが完全に無音) |

既定値70%で、L-only入力に対するエネルギー加重中心バイアスは幾何学的
半径の**94%**に達する。これは実質的に「2つのダンサーが対等に踊っている」
のではなく「ほぼ1つのダンサーだけが踊っていて、もう1人は蚊帳の外」という
状態であり、"DNAらしさ"の核である「2つが常に拮抗している」という体験を
まさに壊す典型例になる。

同じ導出を7条件で行うと、バイアスは**LとRのレベル非対称性**によって
決まり、相関やステレオ幅そのものには依存しないことが分かる(全条件、
`E[mid*side] = 0`ならバイアスは常に0):

| 条件 | L,Rの関係 | bias_fraction (p=0.7) |
|---|---|---:|
| dual mono | L=R | 0(常に0、pに無関係) |
| L-only | L=x, R=0 | **0.940** |
| R-only | L=0, R=x | **-0.940**(符号反転) |
| L/R 6dB差 | R = 0.501*L | 0.441 |
| 非相関ステレオ(等パワー) | E[LR]=0, 等パワー | 0(等パワーなら常に0) |
| 逆相 | L=-R | 0(Mid=0なので両ストランドとも常に無音。P0とは別問題) |
| ワイドパッド(等パワー・相関あり) | 等パワー | 0(等パワーなら常に0) |

**結論**: エネルギー加重中心バイアスは、LとRの**パワーが等しくない**場合
にのみ発生する。ハードパン/一方のチャンネルに偏った素材(L-only、
ボーカルダブルの片側、SEの一方チャンネル送りなど)で最大になり、
「ワイドなステレオパッド」のような一般的な意味での"広いステレオ"素材
では(左右のパワーがだいたい等しい限り)問題にならない。この区別は
重要で、Stereo Preserveの主要ユースケース(パッド・ボーカル・ギター)
そのものは実害が比較的小さい一方、ハードパン素材という無視できない
サブケースでは深刻だったことを意味する。

## 3. 3方式の比較

### 方式A: `sourceA = M + p*S`, `sourceB = M - p*S`(ADR-003、廃止)

上記の通りエネルギー加重中心バイアスが最大p*100%近くまで到達する。

### 方式B: Mid軌道 + 独立したSide bed(採用)

```
両ストランド・Coreのソース = Mid (pに関係なく常に)
bed_L = p * Side
bed_R = -p * Side
wetL = strand+core(Midベース) + bed_L
wetR = strand+core(Midベース) + bed_R
```

Strand A/Bのソースは**常に同一の`Mid`信号**なので、`E_A ≡ E_B`が
構造的に(近似ではなく代数的に)保証される。ゆえにエネルギー加重中心
バイアスは**入力に関わらず常に厳密に0**。Side成分は「軌道を回らない
独立したベッド」として直接加算することで、ステレオ幅の復元と
anti-phase入力時の無音化回避を実現する。

p=0では`bed = 0`となり、Strand/Coreのソースは(旧方式でも同じく)
`Mid`のみだったため、**p=0の出力は数式レベルで方式Aのp=0と完全に
同一**である。したがってschema 1互換性を一切損なわずに移行できる。

### 方式C: A/Bの長期エネルギーを緩やかに均衡化

方式A(`sourceA = M ± p*S`)を維持したまま、StrandごとのOutput RMSを
数百ms〜1秒の時定数で追跡し、長期的に均衡させるようゲイン補正をかける。

**却下**。理由:
- 本プロジェクトのAuto Gain設計哲学(`HelixEngine.cpp`の`wetMakeup`
  コメント: "Deterministic (not signal-following, so it cannot pump)")
  と正面から矛盾する。信号追従型のゲイン補正は定義上ポンピングの
  リスクを持ち込む。
- 静的な極端ケース(L-onlyが継続する)では、収束するまでの間
  Strand Bの音量が時間とともに変化し続ける - これ自体が「不自然に
  片方が浮かび上がってくる」という新しい可聴アーティファクトになりうる。
- 方式Bが同じ問題を**信号追従なしで、構造的に**解決できる以上、
  信号追従という余分なリスクを取る理由がない。

## 4. 測定

`Tools/StereoPreserveAnalysis.cpp`(実際のHelixEngineを使用、
リポジトリに保存済みで再実行可能)で、7条件 × Stereo Preserve
{0, 25, 50, 70, 100}%を測定した(rateHz=2.0Hzで複数周回分を平均)。

```
condition                   p      rmsL      rmsR   L-R(dB)   monoSum      corr
--------------------------------------------------------------------------------
dual mono (L=R)          0.00   0.19743   0.19880    -0.060   0.29358     0.686
dual mono (L=R)          1.00   0.19743   0.19880    -0.060   0.29358     0.686   (pに無関係)

L-only                    0.00   0.09872   0.09940    -0.060   0.14679     0.686
L-only                    0.70   0.20086   0.12897     3.848   0.14679    -0.461
L-only                    1.00   0.25459   0.17575     3.219   0.14679    -0.700

anti-phase (L=-R)        0.00   0.00000   0.00000     0.000   0.00000     1.000
anti-phase (L=-R)        0.70   0.27074   0.27074     0.000   0.00000    -1.000

wide stereo pad          0.00   0.10735   0.10810    -0.061   0.14883     0.675
wide stereo pad          0.70   0.17386   0.17197     0.095   0.14877    -0.351
```

(全条件・全p値は上記ツールの出力、またはコミット履歴のログを参照。)

**最重要の観測事実**: `monoSum`(`|L+R|`の平均)が、**すべての条件で
Stereo Preserveの値に関わらずほぼ一定**である(L-only: 0.14679で完全一致、
wide pad: 0.14872〜0.14886で変動0.1%未満)。これは方式Bの構造から直接
導かれる: bedはSide成分そのもの(`bed_L + bed_R = p*S + (-p*S) = 0`)
なので、モノラルにダウンミックスすると**常に厳密にキャンセルする**。
つまりStrand/Core(Midベース、モノ和で決してキャンセルしない)の寄与量は
pに関わらず一定であり、Stereo Preserveを上げてもモノフォールドダウンの
安全性は一切悪化しない。

**副次的な観測事実**: L-onlyやワイドパッドでは、p増加とともに出力の
相関(`corr`)が下がり、非常に高いp(特にL-only等の極端な非対称入力)
ではむしろ負の相関(位相差の強い/ワイドな出力)になる。これはbedの
Side成分が、Midベースの対称な床(floor)に対して量的に優勢になっていく
ためで、「元の素材が持っていたSide成分をそのまま通している」だけであり
新たな人工的な位相操作ではないが、p=100%付近での聴感(不自然にワイド/
phasyに感じないか)は実試聴での確認が必要 - `MANUAL_REQUIRED.md`に
明記した。

## 5. 決定

**方式B(Mid軌道 + 独立したSide bed)を採用**。

- P0(anti-phase入力の無音化)は解消したまま。
- エネルギー加重中心バイアスは構造的に0(実測ではなく代数的証明、
  `Tests/StereoPreserveTests.cpp`の"Energy-weighted centre"テストで
  L-only/R-only出力差が理論値と1e-4以内で一致することを直接検証)。
- モノフォールドダウン安全性がStereo Preserveの値に依存しなくなった
  (実測: monoSumが全条件でpに対しほぼ一定)。
- schema 1 (`stereoPreserve=0`)との互換性は数式レベルで保証される
  (bed=0でp=0の出力は方式Aのp=0と同一)。

## 6. Stereo Preserve既定値の再確認

70%は**確定値ではなく現時点の候補**として扱う。上記の測定より、
70%という値自体はエネルギー加重中心バイアスの問題からは(方式Bにより)
解放されたが、「p=100%付近で出力相関が大きく負に振れる」という別の
特性が残っているため、実際の音楽素材での試聴によって最終値を決めるべき
という結論は変わらない。デフォルト値の最終確定は`08_手動試聴_DAW検証
仕様書.md`に基づく人間の試聴後に行う。それまでは70%を暫定候補として
維持する。

## 7. Auto Gain・Mix Lawの追従

- **Auto Gain(Wet Makeup)**: 既存の幾何ベース予測式(`aL,aR,bL,bR,core`
  由来のcoherence予測)は、Strand/CoreのソースがStereo Preserveの値に
  関わらず常に`Mid`である(方式Bの帰結)ため、**stereoPreserveの値に
  関わらず常に正確**になった。以前(方式A)は`p=0`でのみ正確だったが、
  Mid固定化によりこの制約が消えた。ただしbed自体のパワーはこの式に
  含まれない(bedのパワーは入力のMid/Side比という信号依存量に左右され、
  それを幾何のみから予測することは信号適応=ポンピングのリスクを
  取り込むことになるため、意図的に対象外とした)。
  `Tests/LevelMatchTests.cpp`の新規テストで、bed込みの実測偏差が
  4dB以内であることを確認した。
- **相関込みMix Law**: 仕様書§9.2の式(`gD,gW,rho`から`predictedPower`
  を予測し正規化)を実装。DryとWetの相関を200msの単一時定数(仕様書の
  attack/release非対称は簡略化 - 統計的な相関推定であり、素早く検知して
  ゆっくり離すコンプレッサー的な包絡線とは性質が違うため、単一の
  保守的な時定数の方がシンプルで安全と判断)で追跡し、±3dBにクランプ。
  Mix 0%/100%では`predictedPower ≡ 1`となり数式的にこの補正が
  恒等写像になる(既存の"Mix 0% == Dry"不変条件は無傷)。
  `Tests/LevelMatchTests.cpp`に、相関の高いDry/Wetでの
  Mix 50%ラウドネス・バンプが解消されたことを確認するテストを追加。
