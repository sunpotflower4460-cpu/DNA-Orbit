# DNA Orbit 意思決定ログ

## Decision ID

`ADR-010`

## 日付

2026-07-30

## 状態

- Accepted

## 題名

ユーザー試聴フィードバック「効果がまだ薄く感じる」を受け、実測に基づき全factory
presetの強度を引き上げる

## 背景

`Tools/RenderAudioSample.cpp`でレンダリングした試聴サンプルをユーザーが
実際に聴き、「いい感じだが、まだ効果が薄く感じる。プリセットの状態でも
もう少し効いた感じがあるといい」というフィードバックを受けた。推測で
値を動かすのではなく、まず「どのパラメータをどれだけ動かせば体感が
変わるか」を実測することにした。

## 測定方法

新規ツール`Tools/PresetIntensityAnalysis.cpp`(`-DDNA_ORBIT_BUILD_TOOLS=ON`
でビルド)を作成した。モノラル中央定位(L==R)の4音パッド音源を実際の
`HelixEngine`に通し、以下を測定する:

- **width**(`1 - L/R相関`): 0=モノラル、1=完全非相関。「広がっているか」の
  本質的な指標。
- **panMove**(50msウィンドウごとのL/Rバランスのdouble標準偏差、dB):
  「実際にどれだけ動いているか」。当初はpeak-to-peakで実装したが、
  パッドの倍音と2ストランドのディレイが作るコムフィルタのノッチが
  単発の外れ値(depth 95%で10.75dB、twist 12msで16.62dB)を生み、
  指標が実際の可聴印象と乖離した。標準偏差に変更して頑健化した。
- **rmsDb** / **monoDb**: Dry比の出力レベル(ステレオ/モノ折り畳み)。
  「広くなった代わりに音量や耳障りな副作用が出ていないか」の確認。

対照実験として、モノラル入力(Side成分が常に0)でStereo Preserveを
0/35/70/100%と振っても4指標が完全に不変(1.18/0.301/-0.55/-1.26で
桁まで一致)であることを確認し、測定方法自体の信頼性を検証した。

## 発見

| パラメータ | 振った範囲 | widthへの影響 |
|---|---|---|
| Mix | 30-100% | 0.078 → 0.485(支配的、ほぼ単調) |
| Core | 0-50% | 0.378 → 0.102(広がりを打ち消す方向) |
| Depth | 45-100% | 0.296-0.312(ほぼ無関係) |
| Twist | 0-20ms | 0.283-0.320(ほぼ無関係) |
| Rate | 0.08-0.80Hz | 0.279-0.320(ほぼ無関係、時間平均指標のため) |

出荷時の"ボーカルを広げる"(Mix 30%, Core 10%)のwidthは**0.045**
(ほぼモノラル相当)だった。「効果が薄い」という指摘は、感覚的な
印象ではなく実測でも裏付けられた。

## 決定

全5つのfactory presetをMix中心に、必要に応じてRadius/Depth/Twist/Core
も引き上げた。widthは以下のように改善した(いずれもMix 60%台へ):

| Preset | 旧width | 新width |
|---|---:|---:|
| ボーカルを広げる | 0.045 | 0.236(5.2倍) |
| パッドを回す | 0.163 | 0.413(2.5倍) |
| ギターに揺らぎ | 0.081 | 0.234(2.9倍) |
| シンセを速く回す | 0.126 | 0.336(2.7倍) |
| 実験:中心を消す | 0.121 | 0.648(NULL COREの性質上さらに広い) |

Rate(回転速度)は時間平均指標にはほぼ現れないが、「フレーズの中で
一周を知覚できるか」に直結するため、遅すぎるプリセット(0.04Hz =
25秒/周、0.08Hz = 12.5秒/周)を0.06Hz/0.11Hzへ少し引き上げた。
Character(音色)は据え置き — こちらは強度ではなく音色を変えるもので、
今回の実測の対象外(ADR-006参照、実測の裏付けがまだない)。

## 検討したが採らなかったこと: NULL CORE presetへの出力トリム補正

"実験:中心を消す"はMix引き上げにより、Auto Gainの予測が前提とする
通常のstrand+core構成とNULL CORE(Mid除去)の実際のWet構成が乖離し、
ステレオで-2.91dB、モノ折り畳みで-4.62dBとDryより顕著に静かになる
ことを実測した。+2.9dBの固定出力トリムでステレオの音量差を埋める
ことを試したが、これは**モノ折り畳みの音量も同じdB分だけ持ち上げて
しまう**(固定ゲインは選択的にかけられない)ため、このpreset唯一の
存在意義である「モノにするとほぼ消える」という効果そのものを弱めて
しまうと判明し、採用しなかった。ステレオでの-2.9dBの静かさは、
Mid成分を完全に除去したことの誠実な帰結として、補正せずそのまま
残した(NULL CORE自体が既に「実験的」と明示され、
`MANUAL_REQUIRED.md`に警告表示に関する既存の注記がある)。

## 理由

- 推測ではなく実測: widthというシンプルな指標がMix・Coreへの依存を
  明確に示し、どのノブを動かせば効くかが数値で分かった。
- 副作用の確認: rmsDb/monoDbの実測により、広さを稼いだ代わりに
  音量が破綻していないこと(NULL CORE以外)を確認した。
- 回帰防止: `Tests/PresetIntensityTests.cpp`により、将来Mix/Coreの
  既定値がうっかり下げられて「また薄く感じる」状態に戻ることを
  自動テストで検出できるようにした。

## 影響

### 良い影響

- 全presetの体感強度が実測で2.5〜5倍程度向上した。
- 強度調整の判断材料(`Tools/PresetIntensityAnalysis.cpp`)が
  再利用可能な形で残り、今後の音づくりにも使える。

### 悪い影響

- Mixを上げた分、Dry比の出力レベルがわずかに下がる
  (-0.66〜-0.82dB、NULL CORE presetのみ-2.91dB)。Auto Gainは
  既定でオンなので大きな聴感差ではないはずだが、実際の聴感確認は
  依然として必要(`MANUAL_REQUIRED.md`参照)。
- 数値は依然として合成のパッド音源による測定であり、実際のボーカル・
  ギター・ドラムなど多様な素材での聴感は保証しない。

### 互換性

- パラメータID・schemaへの影響なし。プリセットの中身(数値)のみの
  変更であり、既存プロジェクトが保存済みの値には一切影響しない。
