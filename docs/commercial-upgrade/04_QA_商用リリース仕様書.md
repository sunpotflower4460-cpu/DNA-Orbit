# DNA Orbit QA・商用リリース仕様書

## 1. QA原則

商用品質は「テスト数が多い」ことではなく、失敗が起こる場所を体系的に塞ぐことで証明する。

QAを次の層に分ける。

1. 数学
2. DSP単体
3. Processor/state
4. Host validation
5. 実DAW
6. 実機性能
7. 手動試聴
8. 署名・配布
9. インストール後検証

# 13. 出荷停止条件

一つでもあればreleaseしない。

- HELIXで一般的ステレオ入力が無音化
- project reloadで音が変わる
- bypass復帰で古い音や大きなclick
- validator failure
- unsigned/notarization failure
- CPU spike
- automation crash
- text corruption
- monoで予告なく大幅消失
- preset再現性なし
- 既知のデータ破損
