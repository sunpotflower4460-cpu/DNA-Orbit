# DNA Orbit 世界基準・商用化アップグレード指示書セット

対象リポジトリ:

- `sunpotflower4460-cpu/DNA-Orbit`
- 想定ブランチ: `main`
- 現在の基盤: C++20 / JUCE 8.0.15 / CMake
- 現在の形式: Standalone / VST3 / AU

このパッケージは、DNA Orbitを「独創的な技術デモ」から「安心して販売できる世界基準の音楽制作プラグイン」へ引き上げるための設計・実装・検証一式です。

## 開発方針

### 先に完成させるもの

1. ステレオ情報を保ったままDNA軌道を作る
2. Dry/Wet全域で体感音量が暴れない
3. バイパス復帰・テンポ変更・再生位置変更で破綻しない
4. 同じプロジェクトを同じ位置から再生すると同じ結果になる
5. macOS / Windows /主要DAWで検証可能な状態を作る

### 後回しにするもの

- HRTF
- Atmos / Ambisonics
- マルチバンドDNA
- サイドチェイン
- 多数の軌道形状
- 過剰なアニメーション
- 販売前に不要なアカウント・認証・クラウド機能

---

## 絶対に守ること

- 既存のパラメータIDは変更しない
- 音声スレッドでメモリ確保・ロック・ファイルI/O・UI操作をしない
- 「聴いた」「実機で確認した」と、実際に行っていないことを記載しない
- README上の説明ではなく、テスト・測定・実機確認で完成を証明する
- 大規模な一括書き換えを避け、フェーズごとに小さくコミットする
- 既存プロジェクトを読み込んだときの音を、必要以上に変えない
- 新しいDSPを入れる場合は旧挙動を再現できる互換モードか移行方針を持つ
